# PROJECT NANO CORELY HEAD APP

This is the source code to build the android head app for Project Nano Corely. After downloading/cloning, You can use this as a project folder in android studio to build this app specifically for your android device.

## Control Instruction
- BOOT : Wake Corely up. this may take a while, so please do not close the app while the system is starting up
- STOP : Stop the system.
- DREAM : Start the consolidator to process unconsolidated memories.
- SLEEP : Stopping the system and immediately start the consolidator.
